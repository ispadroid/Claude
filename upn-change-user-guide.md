# Guida Utente — Cambio UPN (User Principal Name)

> **Cosa cambia per te?** Il tuo indirizzo email / nome utente aziendale è stato aggiornato.
> Alcune applicazioni Microsoft 365 richiedono pochi passaggi manuali per riallinearsi al nuovo account.

---

## OneNote — Ricollegare i blocchi note

Dopo il cambio UPN, i blocchi note OneNote potrebbero risultare inaccessibili o mostrare un errore di sincronizzazione. Segui questi passaggi:

### Passaggio 1 — Chiudi tutti i blocchi note aperti in OneNote

1. Apri **Microsoft OneNote** (desktop o app).
2. Per ogni blocco note visibile nel pannello laterale sinistro:
   - Fai clic destro sul nome del blocco note.
   - Seleziona **Chiudi blocco note**.
3. Ripeti per tutti i blocchi note finché il pannello è vuoto.
4. Chiudi completamente l'app OneNote.

### Passaggio 2 — Accedi a OneDrive Web e apri il blocco note da lì

1. Apri il browser e vai su **[onedrive.com](https://onedrive.com)**.
2. Accedi con il **nuovo indirizzo email / UPN**.
3. Naviga fino alla cartella che contiene il tuo blocco note (file `.one` o cartella con il nome del blocco note).
4. Fai clic sul blocco note → verrà aperto in **OneNote per il Web**.
5. In OneNote per il Web, clicca su **"Apri in OneNote"** (in alto a destra) per aprirlo nell'app desktop.

> Aprire il blocco note direttamente da OneDrive Web forza il riallineamento delle credenziali al nuovo UPN.

### Risultato atteso

Il blocco note è nuovamente sincronizzato e accessibile nell'app OneNote con il nuovo account.

---

## OneDrive — Ricondivisione dei file e delle cartelle

Le condivisioni precedentemente create con il vecchio UPN vengono invalidate durante il cambio di account. **I destinatari perderanno l'accesso** ai file e alle cartelle che avevi condiviso.

### Cosa devi fare

1. Accedi a **[onedrive.com](https://onedrive.com)** con il nuovo indirizzo email.
2. Individua tutti i file e le cartelle che avevi condiviso in precedenza.
   - Suggerimento: usa la visualizzazione **"Condivisi"** nel pannello sinistro per avere una panoramica.
3. Per ogni elemento condiviso:
   - Fai clic destro → **Condividi** (oppure seleziona l'icona di condivisione).
   - Reinserisci i destinatari (nome o indirizzo email).
   - Imposta nuovamente il livello di autorizzazione (**Visualizzazione** o **Modifica**).
   - Invia la nuova condivisione.

> **Nota:** Se i destinatari tentano di accedere tramite un vecchio link, riceveranno un errore di autorizzazione. Dopo aver ricondiviso, comunica loro il nuovo link oppure chiedi loro di accettare il nuovo invito.

### Autorizzazioni ereditate (cartelle SharePoint)

Se i file si trovano in una raccolta SharePoint, contatta il tuo amministratore IT: le autorizzazioni sulle raccolte SharePoint vengono gestite centralmente e potrebbero richiedere un riallineamento lato server.

## Riepilogo rapido

| Applicazione | Azione richiesta |
|---|---|
| **OneNote** | Chiudi tutti i blocchi note → aprili da OneDrive Web → poi in app |
| **OneDrive (condivisioni)** | Ricondividi manualmente tutti i file/cartelle precedentemente condivisi |
| **SharePoint** | Contatta l'amministratore IT per le autorizzazioni di raccolta |
